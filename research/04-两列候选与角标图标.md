# 验证 04：两列候选 + 角标 P + 撤掉长条状态栏

- 验证日期：2026-11-02
- 验证方式：真机实测（小狼毫 0.17.4，Python 驱动 rime.dll + 屏幕截图确认渲染结果）
- 结论：**三件事都落地了，11 项旧回归 + 2 项新回归全绿。**

---

## 一、长条状态栏：废弃

`statusbar/pipi_statusbar.py` 是个 Python + ctypes 的分层窗口，做成搜狗那种长条工具栏。
实际用下来没价值（它连的标点/简繁开关用的人并不多），已整体挪到 `_cancelled/statusbar/`，
并且不再设置开机自启（`启动状态栏.vbs` 留着，要复活直接双击）。

顺带说明为什么当初要自己写：**Weasel 没有状态栏这个组件**，只有托盘图标 + 候选窗两块 UI。
想加任何工具条都得自己起一个进程，用文件当 IPC 通道（`pipi-state.json` / `pipi-cmd.json`）。
Lua 那边的读写代码保留着，不占什么开销，将来要复活不用重写。

## 二、角标换成 P：真正生效的键名是 `schema/icon`

### 踩的坑

之前一直不生效，看到的是小狼毫自带的「红方块 A（西文）/ 蓝方块 中（中文）」。
两个原因叠在一起：

1. **键名写错**。`weasel.custom.yaml` 里写的是 `style/current_zhung_icon`，
   而 `WeaselServer.exe` 里根本没有这个键（二进制里 grep 出来的键是
   `schema/icon`、`schema/ascii_icon`、`schema/full_icon`、`schema/half_icon`、`schema/zhung_icon`）。
   这些是 **schema 级**配置，要写进方案的 patch 里，不是 weasel 的 style。
2. **文件没放对地方**。`luna_pinyin_simp.custom.yaml` 里指向 `pipi-hat.ico`，
   但用户目录 `%APPDATA%\Rime\` 下根本没有这个文件（图标当时还躺在项目 assets 里）。
   路径解析逻辑在 `RimeWithWeasel.cpp::_LoadSchemaSpecificSettings`：

   ```cpp
   const auto user_dir = WeaselUserDataPath();      // %APPDATA%\Rime
   const auto shared_dir = WeaselSharedDataPath();  // 安装目录\data
   if (fs::is_regular_file(user_dir / resource))   return (user_dir / resource).wstring();
   else if (fs::is_regular_file(shared_dir / resource)) return (shared_dir / resource).wstring();
   return std::wstring();   // 两个都没有 → 空 → 回落到内置 IDI_ZH / IDI_EN
   ```

   所以图标必须**实际存在于用户目录**，只写名字没用。

### 现在的做法

- `assets/make_icon_pipi.py`：白底圆角 + 黄框 + 黄 P（`#FFC20A` 框、`#E89800` 字），
  1024 画布画完 Lanczos 降采样出 10 档尺寸（16…256），落成 `pipi-hat.ico` / `pipi-p.ico`。
- 两个 ico 复制到 `%APPDATA%\Rime\`。
- `luna_pinyin_simp.custom.yaml`：`schema/icon` 和 `schema/ascii_icon` 都指向 `pipi-hat.ico`，
  中英两种状态同一个图标——因为皮皮按内容自动判断中英，用颜色区分反而误导。

### 一个必须知道的时序

托盘图标要等**有输入会话**（某个 App 里激活输入法）才会加载 schema 设置并刷新。
刚重启 `WeaselServer.exe` 时还是内置的红 A，敲第一个字母后才变 P。
这是 `_LoadSchemaSpecificSettings` 的调用时机决定的，不是配置没生效。

## 三、两列候选：文字 + 拼音

### 第二列从哪来

librime 自带 `spelling_hints`，会把候选的拼写写进 candidate 的 comment。
**键名在 translator 命名空间下，不是 speller**：

```cpp
// script_translator.cc
config->GetInt(name_space_ + "/spelling_hints", &spelling_hints_);
config->GetBool(name_space_ + "/always_show_comments", &always_show_comments_);
```

```yaml
# luna_pinyin_simp.custom.yaml
"translator/spelling_hints": 24        # 候选码长 <= 24 才给注释，给大就全给
"translator/always_show_comments": true # 拼写与输入框相同时也显示
```

写 `speller/spelling_hints` 是没用的——`name_space_` 取自 `engine/translators` 里组件的
前缀（这里就是 `translator`）。

### 排序逻辑（rime.lua → pipi_filter）

| 自动识别结果 | 候选列表 |
|---|---|
| 像英文（如 `meeting`） | 1. `meeting`（注释「英文」）→ 2..n 中文候选（右侧带拼音） |
| 像拼音（如 `nihao`） | 1. 你好 `ni hao` → … → 第 5 位 `nihao`（注释「拼音」） |

- 空格永远取第 1 位，也就是自动识别出来的那个，行为不变。
- 第 5 位那个「原样拼音」是给输网址/英文混排用的：想让字母原样上屏就按 5。
  位置按 `menu/page_size` 算，固定落在第一页末位，不用翻页。
- 布局改成 `style/horizontal: false`（竖排），一行一个候选，右列才是真正的「列」。
  想换回搜狗那种横铺，把 `style/horizontal` 改回 `true` 即可。

### 踩的坑：Weasel 的颜色是 0xAABBGGRR，不是 RGB

第一版把 `#FFF6DF`（米黄）直接写成 `0xFFF6DF`，渲染出来是**浅蓝**——
因为被解析成 A=FF、B=F6、G=F6、R=DF。所有颜色都要按 ABGR 写：

| 想要 | 正确写法 |
|---|---|
| #FFF3E0 选中底色 | `0xFFE0F3FF` |
| #FFA000 选中文字 | `0xFF00A0FF` |
| #C08A00 选中拼音 | `0xFF008AC0` |

另外 `hilited_back_color`（输入框底色）**不能写 `0x00000000`**，
Weasel 不认 alpha，会直接画成黑块。写实色 `0xFFFFFFFF`。
